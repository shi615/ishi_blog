このブログは **Next.js + MDX** で作っています。
このファイル（`content/posts/hello-world.mdx`）がそのまま1記事になります。

## Markdown がそのまま書ける

見出し、リスト、強調、リンクなど普通の Markdown が使えます。

- 箇条書き
- **太字** や *斜体*
- [リンク](https://nextjs.org)

> 引用も書けます。

## コードブロック

```ts
function greet(name: string) {
  return `Hello, ${name}!`;
}
```
